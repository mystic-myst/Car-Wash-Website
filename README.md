# Car Wash Website

A responsive car wash website designed in Figma and implemented as a functional frontend website.

## Features

* Responsive layout for desktop and mobile screens
* Service and Reviews sections
* Interactive UI elements

## Technologies

* HTML
* SCSS / CSS
* Bootstrap
* Figma

## Design

The website interface was initially designed in Figma and then implemented as a functional frontend.

**Figma Design:** [Link](https://www.figma.com/design/dZqt7E3Lm6I0n1Pa9eCqD5/Car-Wash-Website?node-id=9-148&t=3OAE12dO2pOJFawU-1)
